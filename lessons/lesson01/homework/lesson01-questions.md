## 写疑问的推荐格式

每个疑问一段，照下面的模板填。带 `（可选）` 的可以不写。

```markdown
## 疑问 N
- **在哪里**：（例如：lesson01-lecture.md 第 4 节 / task3 第 28 行 / 自己写的时候）
- **我不懂的是**：（用你自己的话说，说错也没关系）
- **我自己猜过**（可选）：（写了我能知道你的思路卡在哪一步，比只问"为什么"有效 10 倍）
- **想学到什么程度**：（只要会用 / 想彻底搞懂原理）
```

### 小提示：这几类"疑问"也很值得写

不只有"看不懂"才算疑问，下面这些同样价值很高，也欢迎写：

| 类型 | 例子 |
| --- | --- |
| **好奇"为什么"** | "为什么 `main` 非得叫 `main`？叫别的行不行？" |
| **怀疑代码写法** | "我这种写法是不是很笨？有没有更聪明的写法？" |
| **想验证理解** | "我用 `\n` 输出三行，是不是就等于调用了三次 `printf`？" |
| **想提前知道** | "第 5 课的循环，是不是就是用来解决我手写 5 行 printf 这种重复劳动的？" |
| **工具/环境问题** | "`⌘⇧B` 和任务②编译运行到底差在哪？" |
