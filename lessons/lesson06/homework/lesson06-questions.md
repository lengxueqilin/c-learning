# 第 6 课 · 我的疑问（lesson06-questions.md）

> **这个文件是干嘛的**
> 学这一课的过程中，凡是**没听懂、想不通、觉得奇怪**的地方，随手写在这里。
> 不用写得漂亮，写"人话"就行 —— 你写得越具体，我回答得越准。
>
> **什么时候提交**
> 做完作业后对我说一句「**批改第 6 课**」，我会在批改报告之后**逐条回答**这里的疑问。
> 没有疑问也没关系：写一句"本课无疑问"即可。

## 本课特别欢迎这几类疑问（第 6 课的"高危区"）

| 类型 | 可能的疑问 |
| --- | --- |
| **值传递的本质** | "函数拿到的是拷贝 —— 那这个拷贝存在哪儿？为什么改它不会影响原件？" |
| **指针对照** | "讲义说第 9 课用指针就能改外面。能先给我看一眼'长什么样'吗？" |
| **原型的必要性** | "为什么不能把所有函数定义都写在 main 前面，省掉原型？（即为什么要分离）" |
| **递归 vs 循环** | "既然循环更快，为什么还要教递归？除了汉诺塔，还有什么问题非递归不可？" |
| **递归的成本** | "递归比循环慢多少？'栈溢出'到底是什么？" |
| **全局变量** | "既然全局变量这么危险，为什么 C 还允许它存在？有没有正当用法？" |
| **函数返回数组** | "函数能返回一个数组吗？如果不能，那要返回一批数据怎么办？" |
| **参数个数** | "一个函数最多能有几个参数？参数太多了怎么办？" |
| **命名冲突** | "函数名和变量名能一样吗？不同文件里的同名函数会冲突吗？" |
| **`main` 的返回值** | "`main` 的 `return 0` 到底给谁看？别的函数返回值也能被系统看到吗？" |
| **汉诺塔** | "汉诺塔的递归思路我看了好几遍还是绕不过来，能不能再拆细一点？" |

## 疑问示例（**这是示例，不是真疑问，别照着抄**）

> ## 疑问 1
> - **在哪里**：lesson06-lecture.md 第 5 节，值传递
> - **我不懂的是**：讲义说"函数拿到的是实参的一份拷贝"。
>   可是这个拷贝到底在哪？是复制到内存里的另一块地方吗？
>   那如果我传的是一个大数组，岂不是要复制一大片？
> - **我自己猜过**：我猜形参是函数自己的局部变量，所以调用时会把实参的值复制进那个局部变量。
>   这样想的话，"改形参不影响外面"就说得通了。但我不知道这个猜测对不对，
>   也不知道数组是不是也这样。
> - **想学到什么程度**：想有个内存层面的画面感，先不用讲指针的细节。

**为什么这个示例写得好**：它从一个结论（值传递）**往下追问了机制**（拷贝存在哪），
而且**主动猜到"形参就是局部变量"**这个关键点，还联想到"数组会不会也一样"（第 7 课的伏笔）。
带着这样的问题来，我可以直接在你的猜测上补细节，效率最高。

### 小提示

不只有"看不懂"才算疑问，下面这些同样价值很高：

- **想验证理解**："`return` 之后函数里剩下的代码真的不执行吗？"（可以自己跑一下试试）
- **怀疑写法**："我把所有函数原型都写在最上面，函数定义顺序随便，这样可以吗？"
- **想提前知道**："第 7 课的数组，为什么说'传到函数里就能改到原数组'？"
- **觉得奇怪**："为什么 `main` 也是函数？那它是被谁调用的？"
