## 必做 1 ⭐⭐ 成绩等级 + 输入合法性检查

**文件**：[task1_grade.c](task1_grade.c)

**任务**：读入一个分数，输出对应等级；如果分数不在合法范围内，要给出提示。

**等级规则**

| 分数 | 等级 |
| --- | --- |
| 90 ~ 100 | `A` |
| 80 ~ 89 | `B` |
| 70 ~ 79 | `C` |
| 60 ~ 69 | `D` |
| 0 ~ 59 | `F` |
| 小于 0 或大于 100 | **不合法** |

**输出规格**

1. 提示语：`请输入分数（0-100）：`（用 `scanf` 读入一个整数）；
2. 合法时输出一行：`分数 %d -> 等级 %c`
3. 不合法时输出一行：`分数 %d -> 分数不合法（应在 0~100 之间）`
4. **必须用 `if / else if / else` 链**（想想为什么不能用 `switch` —— 讲义第 5.4 节有答案）；
5. **范围判断必须写成 `score >= 0 && score <= 100` 的形式**（不能写 `0 <= score <= 100`）。

**我的实测基准表（我会用这张表逐条验你的程序）**

| 输入 | 我实测的标准输出 |
| --- | --- |
| `95` | `分数 95 -> 等级 A` |
| `90` | `分数 90 -> 等级 A` |
| `85` | `分数 85 -> 等级 B` |
| `70` | `分数 70 -> 等级 C` |
| `60` | `分数 60 -> 等级 D` |
| `59` | `分数 59 -> 等级 F` |
| `0` | `分数 0 -> 等级 F` |
| `100` | `分数 100 -> 等级 A` |
| `-5` | `分数 -5 -> 分数不合法（应在 0~100 之间）` |
| `105` | `分数 105 -> 分数不合法（应在 0~100 之间）` |

**我会检查什么**

- 上表 10 组输入逐条比对（尤其 `90`、`100`、`59`、`0` 这些**边界值**）；

## 必做 2 ⭐⭐⭐ 改错题（1 error + 2 warning + **3 个零警告错误**）

**文件**：[task2_fixme.c](task2_fixme.c)

下面这段代码有 **6 个问题**：

- **1 个 error**（编译直接失败）
- **2 个 warning**（编译期能看到）
- **3 个编译器完全不报错、但结果是错的** ⚠️ **本课重点**

```c
#include <stdio.h>

int main(void)
{
    int score = 85;

    if (score = 90) {
        printf("等级：优秀\n");
    }

    if (score >= 90);
    {
        printf("score 达到 90 分\n");
    }

    int a = 3, b = 1, c = 5;
    if (a < b < c) {
        printf("a < b < c 成立\n");
    }

    int x = 2;
    switch (x) {
        case 1:
            printf("一\n");
        case 2:
            printf("二\n");
        case 3:
            printf("三\n");
            break;
        default:
            printf("其他\n");
            break;
    }

    double sum = 0.1 + 0.2;
    if (sum == 0.3) {
        printf("sum 等于 0.3\n");
    } else {
        printf("sum 不等于 0.3\n");
    }

    int level = 0;
    if (score >= 60) {
        level = 4;
    } else if (score >= 90) {
        level = 1;
    } else if (score >= 80) {
        level = 2;
    }
    printf("等级代号 = %d\n", level);

    return 0;
}
```

**要求**

1. 把改正后的**完整代码**写进 `task2_fixme.c`，编译 **0 error 0 warning**；

   - 类型：`error` / `warning` / **零警告逻辑错误**
   - 用你自己的话说清"为什么错、错在哪"
3. **明确标出 3 个"编译器不报错但结果是错的"分别是哪几条**；
4. 运行验证，程序输出必须是（我实测的标准）：

```text

```

**浮点比较的容差写法（这是新模式，直接给你模板）**

```c
/* 浮点数不能用 == 比较，要比较"差值是否足够小" */
double sum = 0.1 + 0.2;
double diff = sum - 0.3;
if (diff < 0.000001 && diff > -0.000001) {
    printf("sum 约等于 0.3\n");
} else {
    printf("sum 和 0.3 差别太大\n");
}
```

**提示（不给答案，给方向）**

## 必做 3 ⭐⭐⭐⭐ 迷你计算器（`switch` + 除法守卫）

**文件**：[task3_calc.c](task3_calc.c)

**任务**：读入"数字 运算符 数字"，用 `switch` 输出计算结果。

**要求**

1. 提示语：`请输入表达式（格式：数字 运算符 数字，例如 7 * 2）：`
2. **一次读入三个值**（用这个 `scanf`，直接给你，本课的重点不是输入格式）：
   ```c
   scanf("%d %c %d", &a, &op, &b);
   ```
3. 支持 5 种运算符：`+` `-` `*` `/` `%`
4. **除法 `/` 和取余 `%` 必须先判断除数是否为 0**（第 3 课那台机器上 `7 / 0` 会静默返回 0，所以必须自己拦）；
5. 不认识的运算符要给出提示；
6. **必须用 `switch`**（这一题就是练它）；但"除数是不是 0"的判断要用 `if`（范围/条件判断用 `if`）。
7. 说明：`a`、`b` 是整数，所以 `/` **用整数除法**，`7 / 2 = 3`（这是预期行为，不要改成小数）。

**我的实测基准表（我会逐条验）**

| 输入 | 我实测的标准输出 |
| --- | --- |
| `7 + 2` | `7 + 2 = 9` |
| `7 - 2` | `7 - 2 = 5` |
| `7 * 2` | `7 * 2 = 14` |
| `7 / 2` | `7 / 2 = 3` |
| `7 % 2` | `7 % 2 = 1` |
| `7 / 0` | `7 / 0：除数不能为 0` |
| `7 % 0` | `7 % 0：除数不能为 0` |
| `7 @ 2` | `不支持的运算符：@` |

**我会检查什么**

- 上表 8 组输入逐条比对（尤其 `7 / 0` 和 `7 @ 2` 这两个"异常路径"）；
- 是否真的用了 `switch`，每个 `case` 是否都有 `break`；
- 除法守卫是否真的拦住了（不是靠"反正不崩溃"混过去）；
- 0 错误 0 警告。

## 选做 4 ⭐⭐⭐⭐⭐ 根据年月输出该月天数（**正当的 fallthrough**）

**文件**：[challenge_month.c](challenge_month.c)

**任务**：读入年份和月份，输出这个月有多少天（2 月要考虑闰年）。

**要求**

1. 提示语：`请输入年份和月份（空格隔开）：`
2. 用 `scanf("%d %d", &year, &month);` 读入两个整数；
3. **必须用 `switch` 的"空 case 连写"技巧**（多个 `case` 共享同一段代码）——
   这一题就是让你体验 fallthrough 的**正当用法**；
4. 2 月要用第 3 课的闰年表达式判断 28 还是 29 天；
5. 月份不在 1~12 时，输出 `月份 %d 不合法`；
6. **思考题**（写在注释里）：
   > 这一题里 `case` 后面有"故意不写语句"的情况（比如 `case 1: case 3: ...`），
   > 为什么这里的 fallthrough 是**正当的**，而不是 bug？
   > （提示：想想"谁来执行 `days = 31;`"这件事）

**我的实测基准表**

| 输入 | 我实测的标准输出 |
| --- | --- |
| `2024 2` | `2024 年 2 月有 29 天` |
| `2023 2` | `2023 年 2 月有 28 天` |
| `2000 2` | `2000 年 2 月有 29 天` |
| `1900 2` | `1900 年 2 月有 28 天` |
| `2024 1` | `2024 年 1 月有 31 天` |
| `2024 4` | `2024 年 4 月有 30 天` |
| `2024 11` | `2024 年 11 月有 30 天` |
| `2024 13` | `月份 13 不合法` |
| `2024 0` | `月份 0 不合法` |

**为什么做这题**：这题把**本课（switch）** 和 **第 3 课（闰年表达式）** 拼在一起，
而且让你写到"故意贯穿"—— 从"怕这个东西"变成"会用这个东西"，是理解的分水岭。
