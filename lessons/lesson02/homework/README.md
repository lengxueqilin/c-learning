## 必做 1 ⭐ 个人档案表（练宽度控制）

**文件**：[task1_profile.c](task1_profile.c)

**任务**：定义三个变量存你自己的真实数据，然后用 `printf` 输出一张表。

| 变量 | 类型 | 内容 |
| --- | --- | --- |
| 年龄 | `int` | 你的真实年龄 |
| 身高 | `double` | 你的身高（单位：米，例如 `1.75`） |
| 首字母 | `char` | 你名字的拼音首字母（例如 `'L'`） |

**输出规格（必须严格满足，我会逐字符测量）**

1. 第一列＝标签，**宽 8、左对齐**；第二列＝数值，**宽 8、右对齐**；
2. 两列之间用 ` | ` 分隔；每行以 `| ` 开头，以 ` |` 结尾；
3. 身高列**保留 2 位小数**；
4. 上、下边框用 `+` 和 `-` 画，**总宽度必须和内容行完全一致**（宽度自己算出来，我实测比对）；
5. **只允许用宽度控制对齐** —— 不许手数空格，不许用 `\t`（这一题就是练这个）；
6. 三行的顺序固定为：`Age`、`Height`、`Grade`。

**形状示意（数值是示例，你要用自己的数据；注意 `|` 的位置不要变）**

```text
+---------------------+
| Age      |       18 |
| Height   |     1.75 |
| Grade    |        L |
+---------------------+
```

（上面这个形状是**程序真实输出**，不是我手写的。你可以数一数每行多少字符，那就是边框该有的宽度。）

**我会检查什么**

- 4 条边框和 3 行内容的**总宽度是否完全一致**（逐字符测量）；
- 第一列是否左对齐、第二列是否右对齐；
- 是否用了宽度控制（`%-8s` / `%8d` / `%8.2f` / `%8c`）而不是手敲空格；
- 0 错误 0 警告。

## 必做 2 ⭐⭐ 改错题（5 处编译期问题 + 1 处隐形错误）

**文件**：[task2_fixme.c](task2_fixme.c)

下面这段代码有 **6 个问题**：

- **1 个 error**（编译直接失败）
- **4 个 warning**（能编译，但都是隐患 —— 其中 1 个会导致运行时段错误崩溃）
- **1 个编译器完全不报错、但结果是错的**（⚠️ 本课重点，全在你自己）

> 🔎 **一个重要提示：你第一次编译，只会看到 1 个 error + 3 个 warning。**
> 因为**error 会挡住一部分 warning** —— 那个"未初始化"的警告要等你把 error 修好、
> 重新编译之后才会浮现出来。
> 这正是第 1 课我说的那句话的现场证据：**"只改第一条 error，然后重新编译"**。
> （所以别指望一次编译就把所有问题看全，**改一点、编译一次**才是正确节奏。）

```c
#include <stdio.h>

int main(void)
{
    int age = 18;
    double height = 1.75;

    printf("年龄：%d 岁\n", height);

    int score;
    printf("分数：%d\n", score);

    printf("请输入你的年龄：");
    scanf("%d", age);

    char level = "A";

    int average = (90 + 81) / 2;
    printf("平均分：%.2f\n", average);

    printf("身高：%.2f，等级：%c\n", height, level);

    return 0;
}
```

**要求**

1. 把改正后的**完整代码**写进 `task2_fixme.c`；
2. 在文件的「错误分析」区**逐条写出 6 个问题**，每条包含：
   - 大概位置（哪一行）
   - 属于哪一类：`error` / `warning` / **编译器不报错的逻辑错误**
   - 用你自己的话说清"为什么错"
3. **特别要求**：明确指出哪一条是"**编译器不报错但结果是错的**"，并说明你改成了什么；
4. 运行验证：**平均分必须输出 `85.50`**（如果你改完是 `85.00`，说明那处隐形错误没找到）；
5. 0 错误 0 警告。

**我会检查什么**

- 6 处是否全部正确处理；
- 错误分析能否分清 **error / warning / 隐形错误** 三类；
- 平均分是不是 `85.50`（这是那处隐形错误是否真的改对了的硬证据）。

## 选做 4 ⭐⭐⭐⭐ 算法加练：交换两个变量

**文件**：[challenge_swap.c](challenge_swap.c)

**任务**：读入两个整数 `a` 和 `b`，把它们的值**交换**，然后输出。

**要求**

1. 输出必须先显示**交换前**，再显示**交换后**，例如：

```text
请输入两个整数（空格隔开）：3 8
交换前：a = 3, b = 8
交换后：a = 8, b = 3
```

2. 必须**借助一个临时变量**完成交换（这是最标准、最安全的做法）；
3. 在文件注释里回答这个**思考题**（不用写代码，写文字）：
   > 不借助第三个变量，能不能完成交换？如果你有想法，说说你的思路。
   > （提示：这要用到第 3 课才学的算术运算符，先随便猜，猜错完全没关系）
4. 0 错误 0 警告。

**为什么做这题**：交换两个变量是**算法思维的起点** ——
它让你第一次体会"**数据在变量之间搬家**"这件事。后面学排序（第 7 课）时，
你会发现排序的每一个动作，都是"交换"。
