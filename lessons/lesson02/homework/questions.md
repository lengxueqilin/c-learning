# 第 2 课 · 我的疑问（questions.md）

> **这个文件是干嘛的**
> 学这一课的过程中，凡是**没听懂、想不通、觉得奇怪**的地方，随手写在这里。
> 不用写得漂亮，写"人话"就行 —— 你写得越具体，我回答得越准。
>
> **什么时候提交**
> 做完作业后对我说一句「**批改第 2 课**」，我会在批改报告之后**逐条回答**这里的疑问。
> 没有疑问也没关系：写一句"本课无疑问"即可。

---

## 写疑问的推荐格式

```markdown
## 疑问 N
- **在哪里**：（例如：lecture.md 第 5 节 / task3 第 20 行 / 自己写的时候）
- **我不懂的是**：（用你自己的话说，说错也没关系）
- **我自己猜过**（可选）：（写了我能知道你的思路卡在哪一步）
- **想学到什么程度**：（只要会用 / 想彻底搞懂原理）
```

## 本课特别欢迎这几类疑问（第 2 课的"高危区"）

| 类型 | 可能的疑问 |
| --- | --- |
| **`&` 到底是什么** | "为什么 `scanf` 要 `&`，`printf` 不要？`&a` 到底是个什么东西？" |
| **`%lf` 与 `%f`** | "为什么输出用 `%f`、输入要用 `%lf`？不都是 `double` 吗？" |
| **整数除法** | "为什么 `7/2` 是 3？那 `7.0/2` 为什么就对了？规则到底是什么？" |
| **宽度控制** | "`%8.2f` 里的 8 和 2 谁先谁后？如果既要宽度又要精度怎么办？" |
| **输入缓冲区** | "第 5.5 节那个'回车被吃掉'，我完全没看懂，能再讲一遍吗？" |
| **类型选择** | "既然 `double` 什么都能装，为什么还要用 `int` 和 `float`？" |
| **环境相关** | "任务②运行时，我怎么知道该在哪里敲数字？" |

### 小提示

不只有"看不懂"才算疑问，下面这些同样价值很高：

- **想验证理解**："我用 `%8.2f` 打印 3.14159，输出是不是 `    3.14`？"
- **怀疑写法**："我用 `printf` 一行输出一整张表，会不会太长了？应该拆开吗？"
- **想提前知道**："第 3 课的 `%` 取余，跟 `printf` 里的 `%` 是同一个符号吗？"
- **觉得奇怪**："为什么 `int` 是 4 字节、`char` 是 1 字节，这个数字是谁定的？"
