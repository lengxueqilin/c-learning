## 1. `while` 循环：三要素，缺一个都不行

打开 [examples/01_while.c](examples/01_while.c)，**本机真实输出**：

```text
1~5：1 2 3 4 5
倒数：5... 4... 3... 2... 1... 发射！
1 + 2 + ... + 100 = 5050
拆解 98765 的每一位（从个位开始）：5 6 7 8 9
它共有 5 位
x = 10，下面的循环体一次都不会执行：（直接跳过）
```

### 1.1 三要素

```c
int i = 1;              /* ① 初始化：给"控制变量"一个起始值 */
while (i <= 5) {        /* ② 条件：成立就执行循环体 */
    printf("%d ", i);
    i++;                /* ③ 更新：改变控制变量，否则【死循环】 */
}
```

| 要素 | 作用 | 少了它会怎样 |
| --- | --- | --- |
| ① 初始化 | 给变量一个起点 | 变量里是垃圾值，循环次数不确定 |
| ② 条件 | 决定"还继续吗" | —— |
| ③ 更新 | **让条件最终能变假** | **死循环，程序永远不会停** |

> **记住这句话：每个循环都必须有人负责让条件变假。**
> 这是本课最重要的一条纪律，后面第 4 节和第 7 节都会回到它。

### 1.2 累加器模式：`sum += x`

```c
int sum = 0;            /* 累加器：从 0 开始 */
int n = 1;
while (n <= 100) {
    sum += n;           /* 每次都往 sum 里加一点 */
    n++;
}
printf("1 + 2 + ... + 100 = %d\n", sum);     /* 5050 */
```

**这个模式你会用一辈子。** 求和、求平均、统计个数，全是它。

### 1.3 条件不一定是"计数"（第 3 课的零件终于装上了）

第 3 课我讲"数位拆解"时说过：`%` 取一位、`/` 砍一位，
"只是现在手工重复了 3 次，第 5 课学了循环就能让机器自己重复"。现在兑现：

```c
int num = 98765;
int digits = 0;
while (num > 0) {           /* 条件是"还有数字没拆完" */
    printf("%d ", num % 10);
    num /= 10;              /* 更新：让 num 越来越小，最终变成 0 */
    digits++;
}
```

**实测输出**：`5 6 7 8 9`（从个位开始），共 5 位。

**注意这个 while 的结构和第 1 节完全一样**（初始化 / 条件 / 更新），
只是"更新"变成了 `num /= 10` —— 它同样**负责让条件最终变假**。

### 1.4 循环体一次都不执行的情况

```c
int x = 10;
while (x < 5) { ... }      /* 条件一开始就是假 → 一次都不执行 */
```

`while` 是**先判断、后执行**。如果第一次判断就不成立，循环体一次都不跑。

## 2. `for` 循环：计数循环的专用写法

打开 [examples/02_for.c](examples/02_for.c)：

```text
1~5：1 2 3 4 5
从 0 开始：0 1 2 3 4
倒着数：5 4 3 2 1
步长 5  ：0 5 10 15 20
每次除以 2：100 50 25 12 6 3 1
1 + 2 + ... + 100 = 5050
1~100 中能被 7 整除的数有 14 个
重复打印：====================
循环结束后 j 仍然存在：j = 3
k = 10
```

### 2.1 语法

```c
for (初始化; 条件; 更新) {
    循环体;
}
```

**它和 `while` 完全等价：**

```text
for (A; B; C) { D; }     ==     { A; while (B) { D; C; } }
```

**为什么日常更爱用 `for`？** 因为三要素**写在一行里，跑不掉**。
用 `while` 时很容易忘记写 `i++`（这就是死循环的头号原因）。

### 2.2 常见变体

```c
for (int i = 1; i <= 5; i++)     /* 1 到 5 —— 最标准 */
for (int i = 0; i < 5; i++)      /* 0 到 4 —— 第 7 课数组会用这种（记住它！） */
for (int i = 5; i >= 1; i--)     /* 倒着数 */
for (int i = 0; i <= 20; i += 5) /* 步长 5 */
for (int i = 100; i >= 1; i /= 2) /* 每次除以 2 */
```

> ⭐ **`i < n` 从 0 开始**这个写法请现在就熟悉 ——
> 第 7 课数组的下标从 0 开始，届时你会写上百遍 `for (int i = 0; i < n; i++)`。

### 2.3 关于 `i` 的作用域（一个小知识点）

在 `for` 括号里声明的 `i`，**出了这个循环就不存在了**：

```c
for (int i = 0; i < 3; i++) { ... }
printf("%d", i);        /* ❌ 编译错误：i 未声明 */
```

如果循环结束后还需要这个数，就在外面声明（老式写法）：

```c
int j = 0;
for (j = 0; j < 3; j++) { }
printf("j = %d\n", j);  /* ✅ 3 */
```

**为什么 C99 要这么设计？** 让变量的作用域**尽可能小**，减少互相干扰。
这是好设计 —— 但对新手来说，就是一个要记住的规则。

## 3. `do-while`：至少执行一次

打开 [examples/03_do_while.c](examples/03_do_while.c)：

```text
x = 10，条件是 x < 5
while 版    ：（一次都没执行）
do-while 版 ：至少执行了一次

while 计数    ：1 2 3
do-while 计数：1 2 3
```

### 3.1 语法与关键区别

```c
do {
    循环体;
} while (条件);          /* ⚠️ 结尾这个分号不能少！ */
```

| | 判断时机 | 循环体至少执行 |
| --- | --- | --- |
| `while` | **先判断**，后执行 | **0 次** |
| `do-while` | **先执行**，后判断 | **1 次** |

### 3.2 它真正有用的场景：**输入校验**

这是 `do-while` 的最佳现场 —— **先读一次，不合法就再读一次**：

```c
int score = -1;                 /* 故意给个非法初值，保证能进循环 */
do {
    printf("请输入 0~100 的分数：");
    scanf("%d", &score);
    if (score < 0 || score > 100) {
        printf("  %d 不合法，请重新输入\n", score);
    }
} while (score < 0 || score > 100);      /* 不合法就再转一圈 */
```

**实测运行（我依次输入了 `150` 和 `85`）：**

```text
--- 输入校验（请依次输入，非法值会被要求重输）---
请输入 0~100 的分数：  150 不合法，请重新输入
请输入 0~100 的分数：你输入的合法分数是 85（共尝试 2 次）
```

**为什么这里非用 `do-while` 不可？**
因为"**至少要读一次**" —— 用 `while` 的话，你得在循环外面先读一次，
再在循环里面读一次，代码重复。`do-while` 一句解决。

> 💡 记住这个用法，**第 4 课作业 4-1 的"输入合法性检查"，用 `do-while` 会更漂亮** ——
> 那次你用的是 `if`，一次输入不合法就直接退出了；而真实程序应该**给用户重试的机会**。

## 4. `break` 与 `continue`

打开 [examples/04_break_continue.c](examples/04_break_continue.c)：

```text
找到第一个能被 7 整除的数：7
只打印奇数（偶数被 continue 跳过）：1 3 5 7 9

break    at 5 ：1 2 3 4
continue at 5 ：1 2 3 4 6 7 8 9 10

--- 嵌套循环里的 break（只跳一层）---
(1,1) (1,2)  <- 内层在 j=3 时 break 了，但外层 i=1 还在继续
(2,1) (2,2)  <- 内层在 j=3 时 break 了，但外层 i=2 还在继续
(3,1) (3,2)  <- 内层在 j=3 时 break 了，但外层 i=3 还在继续
结论：break 只跳出【离它最近的那一层】循环。

--- 想跳出两层：用标志变量 ---
找到 i=2, j=2，两层都跳出

--- 循环里的 break 会不会被 switch 的 break 带出去？---
外层第 1 轮：switch 走 default；【循环还在继续】
外层第 2 轮：switch 命中 case 2，执行 break；【循环还在继续】
外层第 3 轮：switch 走 default；【循环还在继续】
结论：switch 里的 break 只结束 switch，不会结束外面那层循环。
```

### 4.1 一句话区分

| 语句 | 作用 |
| --- | --- |
| `break` | 立刻**结束整个循环**（跳到循环外面） |
| `continue` | **跳过本次剩下的语句**，直接进入下一轮 |

**对比**：`1~10` 里"遇到 5 就停" vs "跳过 5 继续"：

```text
break    at 5 ：1 2 3 4
continue at 5 ：1 2 3 4 6 7 8 9 10
```

### 4.2 ⚠️ 重点：嵌套循环里，`break` 只跳出一层

```c
for (int i = 1; i <= 3; i++) {
    for (int j = 1; j <= 5; j++) {
        if (j == 3) {
            break;          /* 只结束内层 j 循环 */
        }
        printf("(%d,%d) ", i, j);
    }
    printf(" <- 内层 break 了，但外层 i=%d 还在继续\n", i);
}
```

**想跳出两层？用标志变量：**

```c
int found = 0;                                  /* 标志变量 */
for (int i = 1; i <= 3 && !found; i++) {        /* 外层条件里检查它 */
    for (int j = 1; j <= 3; j++) {
        if (i * j == 4) {
            found = 1;                          /* 立起标志 */
            break;                              /* 先跳内层，外层条件会看到标志 */
        }
    }
}
```

> Java 有 `break label;` 可以直接跳两层，**C 没有**。所以 C 程序员写两层跳出，
> 标准做法就是上面这个"标志变量"。你在 Java 里的经验，这里用不上。

### 4.3 `switch` 里的 `break` 和循环里的 `break` 是什么关系？

**同一条规则：结束"离它最近的那个可跳出结构"。**

```c
for (int i = 1; i <= 3; i++) {
    switch (i) {
        case 2:
            printf("switch 命中 case 2，执行 break；");
            break;              /* ← 这个 break 只结束 switch！ */
        ...
    }
    printf("【循环还在继续】\n");     /* 这行照样会打印 */
}
```

**实测输出证明**：三轮循环全都执行到了最后那行 —— `switch` 的 `break` **没有**把循环带出去。

> 这也回答了你在疑问清单里可能会问的那个问题：
> **"循环里的 `break` 和 `switch` 里的 `break` 是同一个东西吗？"**
> 是同**一条规则**、同**一个关键字**，但作用范围是"最近的那个结构"，不是"所有循环"。

## 5. 嵌套循环：双层世界

打开 [examples/05_nested_loops.c](examples/05_nested_loops.c)：

```text
=== 九九乘法表 ===
1*1=1
1*2=2  2*2=4
1*3=3  2*3=6  3*3=9
1*4=4  2*4=8  3*4=12 4*4=16
1*5=5  2*5=10 3*5=15 4*5=20 5*5=25
1*6=6  2*6=12 3*6=18 4*6=24 5*6=30 6*6=36
1*7=7  2*7=14 3*7=21 4*7=28 5*7=35 6*7=42 7*7=49
1*8=8  2*8=16 3*8=24 4*8=32 5*8=40 6*8=48 7*8=56 8*8=64
1*9=9  2*9=18 3*9=27 4*9=36 5*9=45 6*9=54 7*9=63 8*9=72 9*9=81
```

### 5.1 核心认知：**外层走 1 步，内层走完一整圈**

```c
for (int i = 1; i <= 9; i++) {              /* 外层：行 */
    for (int j = 1; j <= i; j++) {          /* 内层：列 */
        printf("%d*%d=%-3d", j, i, i * j);
    }
    printf("\n");                           /* 一行结束才换行 */
}
```

**换行 `printf("\n")` 必须放在外层循环里** —— 这是新手最常见的错位。
判断方法：问自己"换行是每**行**一次，还是每**个**格子一次？"

`%-3d` 是第 2 课学的宽度控制：占 3 格左对齐，保证每一列等宽。

### 5.2 打印图案的三步心法

```text
    *          ← 第 1 行：4 个空格 + 1 个星号
   ***         ← 第 2 行：3 个空格 + 3 个星号
  *****        ← 第 3 行：2 个空格 + 5 个星号
 *******       ← 第 4 行：1 个空格 + 7 个星号
*********      ← 第 5 行：0 个空格 + 9 个星号
```

**心法**：

1. **先找出"第 row 行"的规律**：空格数 = `5 - row`，星号数 = `2 * row - 1`；
2. **每行做两件事**：先补空格，再打星号（两个并排的内层循环）；
3. **别忘了换行**（在外层循环的最后）。

**菱形就是"上半部分 + 倒过来的下半部分"**：

```c
for (int row = 1; row <= size; row++) { ... }          /* 上半：1 → size */
for (int row = size - 1; row >= 1; row--) { ... }      /* 下半：size-1 → 1 */
```

实测输出：

```text
=== 菱形 ===
   *
  ***
 *****
*******
 *****
  ***
   *
```

### 5.3 嵌套循环的代价是"乘法级"

```text
外层 4 次 × 内层 3 次 = 共执行 12 次循环体
```

**外层 n 次、内层 m 次 → 循环体执行 n × m 次。**
这不是小事：第 7 课学排序时，你会看到"两层嵌套循环"直接把 1000 个数据变成 100 万次操作。
**这叫做"时间复杂度"，是后面算法课的核心概念之一。**

## 6. 四个经典循环模式（建议默写）

打开 [examples/06_loop_patterns.c](examples/06_loop_patterns.c)：

```text
=== 模式 1：求最大值 / 最小值 / 平均值 ===
  第  1 个数据 = 37
  ...
  个数 = 10，总和 = 535，最大 = 96，最小 = 11，平均 = 53.50

=== 模式 2：数位拆解 + 数字反转 ===
  原数 = 12345
  位数 = 5
  各位数字之和 = 15
  反转后的数 = 54321

=== 模式 3：二进制里 1 的个数 ===
  13 的二进制是 1101，其中有 3 个 1

=== 模式 4：判断质数 ===
  97 是质数
  91 能被 7 整除，立刻 break（不用再试了）
  91 不是质数
```

### 模式 1：一边遍历一边更新最值

```c
int max = -1;               /* 初始化成"肯定比所有数据都小"的值 */
int min = 101;              /* 初始化成"肯定比所有数据都大"的值 */
for (...) {
    if (value > max) { max = value; }
    if (value < min) { min = value; }
    sum += value;
    count++;
}
printf("平均 = %.2f\n", (double)sum / count);
```

**两个细节**：

- 最值的初始化是个技巧：要么用一个"极端值"，要么**用第一个数据来初始化**（更稳，作业里会用到）；
- 求平均时 `(double)sum / count` —— 第 3 课的整数除法陷阱，别忘。

### 模式 2：数位拆解 + 数字反转

```c
while (n > 0) {
    int digit = n % 10;                 /* ① 取出最后一位 */
    digitSum += digit;                  /* ② 累加 */
    reversed = reversed * 10 + digit;   /* ③ 反转：把旧结果左移一位，再放新数字 */
    n /= 10;                            /* ④ 砍掉最后一位 */
    digits++;
}
```

**第 ③ 步为什么能反转？** 把每一轮摊开看：

```text
第1轮：0 * 10 + 5    = 5
第2轮：5 * 10 + 4    = 54
第3轮：54 * 10 + 3   = 543
第4轮：543 * 10 + 2  = 5432
第5轮：5432 * 10 + 1 = 54321
```

**"乘以 10 等于左移一位"** —— 这个思路以后在很多地方会以别的形式出现。

### 模式 3：数二进制里有多少个 1

```c
while (temp > 0) {
    if (temp % 2 == 1) { ones++; }      /* 看最低位是不是 1 */
    temp /= 2;                          /* 右移一位 */
}
```

**和第 2 个模式完全同构**（都是"取一位 + 砍一位"），只是进制从 10 换成了 2。
> 这个思路在选修课《位运算》里会升级成 `temp & 1` 和 `temp >>= 1`，快得多。

### 模式 4：判断质数（`break` 的经典用法）

```c
int isPrime = 1;                    /* 先假设是质数，发现因子就推翻 */
for (int d = 2; d * d <= candidate; d++) {      /* 只试到 √n */
    if (candidate % d == 0) {
        isPrime = 0;
        break;                      /* 找到一个因子就够了，立刻收工 */
    }
}
```

**两个关键点**：

1. **`break` 让程序"提前收工"** —— 找到一个因子就没必要再试了，这是效率；
2. **`d * d <= candidate` 等价于 `d <= √n`** —— 为什么只试到 √n？见下面思考。

> 🧠 **为什么只需要试到 √n？**（作业选做题会让你回答）
> 如果 `n = a × b` 且 `a ≤ b`，那么一定有 `a ≤ √n`。
> 也就是说：**如果 n 有因子，那它一定有一个 ≤ √n 的因子。**
> 所以试到 √n 就够了 —— 试更大的是白费力气。
> 用 `d * d <= candidate` 而不是 `d <= sqrt(n)`，是为了避免引入 `<math.h>` 和开方的浮点误差。

## 7. ⚠️ 循环的陷阱：**大多是零警告的**

打开 [examples/07_pitfall_playground.c](examples/07_pitfall_playground.c)：

```text
这一行是正常的

陷阱 3 对比：
  i < 5  时求和 = 10   （累加了 4 个数）
  i <= 5 时求和 = 15   （累加了 5 个数）—— 差一个 5！

陷阱 4：以为 break 能跳出两层
  (1,1) 外层 a=1 这一轮还是走完了
  (2,1) 外层 a=2 这一轮还是走完了

陷阱 7 的真相（浮点累加 10 次 0.1）：d = 0.99999999999999988898，它 == 1.0 吗？ 0
```

### 7.1 头号危险：死循环（**编译器完全不警告**）

```c
int i = 0;
while (i < 5) {
    printf("%d ", i);
    /* 忘了 i++;  →  i 永远是 0，条件永远成立，程序永远不会停 */
}
```

**我在你机器上实测了三种死循环，都用 1 秒超时确认"停不下来"：**

| 死循环写法 | 为什么会死 |
| --- | --- |
| `while (i < 5) { printf(...); }` | 忘了 `i++` |
| `for (int k = 0; k < 10; ) { if (k % 2 == 0) { continue; } k++; }` | `continue` **跳过了 `k++`** |
| `while (1) { }` | 条件本来就是"永远真" |

**怎么中止？** 在运行它的终端里按 **`Control + C`**。

**怎么预防？三要素检查法**（每次写完循环问自己）：

1. **初始化**了吗？
2. **条件**会在某一刻变成假吗？
3. **更新**在哪？**谁负责让条件变假？**

> ⚠️ 第 3 条最容易漏，尤其是 **`continue` 把更新语句跳过**这种情况 ——
> 这个坑**零警告**，而且看起来完全正常。

### 7.2 差一错误（off-by-one）

```c
for (int i = 1; i < 5; i++)  { total += i; }    /* 1+2+3+4 = 10 */
for (int i = 1; i <= 5; i++) { total += i; }    /* 1+2+3+4+5 = 15 */
```

**`<` 和 `<=` 差一次，结果差很多。** 而且**零警告**。

**自检技巧**：拿最小的例子手算。`n = 1` 时循环跑几次？`n = 2` 呢？

### 7.3 `while (...)` / `for (...)` 后面多一个分号

```c
while (i < 3);          /* ⚠️ 这个分号就是循环体（空的）！ */
{
    printf("A ");
    i++;
}
```

**后果分两种（这点必须分清）**：

| 写法 | 后果 |
| --- | --- |
| `while (i < 3);` + 块 | ⚠️ **死循环**（`i++` 在循环外，条件永远成立） |
| `for (int k = 0; k < 3; k++);` + 块 | 循环空转 3 次，然后块执行**一次** |

clang 会警告 `-Wempty-body`（`while loop has empty body` / `for loop has empty body`）——
**这是本课少数几个"编译器会帮你"的地方，看到就改。**

### 7.4 其他三个零警告陷阱

| 陷阱 | 后果 | 修法 |
| --- | --- | --- |
| **`break` 以为能跳两层** | 外层继续跑，多执行了不该执行的代码 | 用标志变量 |
| **`continue` 位置错**（先处理再判断，应该是先判断再处理） | 该跳过的没跳过（实测：奇数和算出 55，应该是 25） | 把"跳过判断"放到处理之前 |
| **循环体里改循环变量** | 次数完全失控（实测：本想 10 次，实际 4 次） | 别在循环体里改它 |

### 7.5 还有一条：`while` 的条件里写赋值

```c
while (i = 5) { ... }       /* 条件恒为真 → 死循环 + 警告 */
```

clang 警告 `-Wparentheses` —— **和第 4 课 `if (x = 5)` 是同一条规则**。
**修法也一样：改成 `==`，别用双括号消警告。**

## 8. 小测验（先自己想，再展开答案）

**Q1.** 循环的三要素是什么？少了哪一个会导致死循环？

**Q2.** `for (int i = 0; i < 5; i++)` 循环体执行几次？`for (int i = 1; i <= 5; i++)` 呢？

**Q3.** `while` 和 `do-while` 最本质的区别是什么？哪个适合做"输入校验"？

**Q4.** 嵌套循环里，`break` 和 `continue` 各自作用于哪一层？

**Q5.** 找出下面代码的死循环原因：
```c
for (int k = 0; k < 10; k++) {
    if (k % 3 == 0) { continue; }
    printf("%d ", k);
}
```

**Q6.** 下面代码想输出 1~5 的和（15），实际输出什么？为什么？
```c
int sum = 0;
for (int i = 1; i < 5; i++) { sum += i; }
printf("%d\n", sum);
```

**Q7.** 下面这个循环会执行几次？为什么？
```c
int steps = 0;
for (int k = 0; k < 10; k++) {
    k += 2;
    steps++;
}
```

<details>
<summary>👉 点这里展开答案与解析</summary>

**A1.** **初始化、条件、更新**。
少了**更新**（比如忘了 `i++`），条件就可能永远成立 → **死循环**。
记住那句话：**"每个循环都必须有人负责让条件变假。"**

**A2.** 两个都执行 **5 次**。
- `i = 0; i < 5`：i 取 0、1、2、3、4 → 5 次；
- `i = 1; i <= 5`：i 取 1、2、3、4、5 → 5 次。

**两种写法都常用**，但要心里清楚：**`<` 配从 0 开始**，**`<=` 配从 1 开始**。
第 7 课数组下标从 0 开始，所以 `i < n` 会是主流写法。

**A3.** **`while` 先判断后执行（可能 0 次）；`do-while` 先执行后判断（至少 1 次）。**
**输入校验用 `do-while`** —— 因为"至少得先读一次才知道合不合法"，用 `while` 会导致代码重复。

**A4.** `break` 和 `continue` 都只作用于 **离它们最近的那一层**循环。
想跳出两层，用**标志变量**（C 没有 `break label;`）。

**A5.** 这个循环 **不会**死循环 —— `k++` 在 `for` 的头部，`continue` 跳不到它。
（`continue` 跳到的是"更新表达式之前"还是"之后"？在 `for` 里，`continue` 会**先执行更新表达式** `k++`，再判断条件。所以没问题。）

> ⚠️ 但同样的写法放进 `while` 就会死循环：
> ```c
> int k = 0;
> while (k < 10) {
>     if (k % 3 == 0) { continue; }   /* ❌ k 永远不增加 → 死循环 */
>     k++;
> }
> ```
> **因为 `while` 没有"头部更新"这一步。**
> 这条差异非常重要：**同样的 `continue`，在 `for` 里安全，在 `while` 里可能致命。**

**A6.** 输出 **`10`**，而不是 15。
因为 `i < 5` 让循环只走到 `i = 4`，累加的是 1+2+3+4 = 10 —— **差一错误（off-by-one）**。
改成 `i <= 5` 才对。

**A7.** 执行 **4 次**。
因为每轮循环体里 `k += 2`，加上 `for` 头部的 `k++`，实际每轮 k 增加 3：
k = 0 → (加2变2，再加1变3) → (加2变5，再加1变6) → (加2变8，再加1变9) → (加2变11，再加1变12) → 12 ≥ 10，循环结束。
**步数统计**：k 依次是 0、3、6、9 时进入循环体 → **4 次**。
**教训：不要在循环体里修改循环变量。**

</details>
