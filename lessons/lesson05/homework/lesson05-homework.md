## 必做 1 ⭐⭐⭐ 哨兵值循环：统计一列数字

**文件**：[task1_loop_stats.c](task1_loop_stats.c)

**任务**：不断地读入整数，**直到读入 `0` 为止**（这个 `0` 叫"哨兵值"，
它只是**结束标志**，不参与统计）。然后输出统计结果。

**要求**

1. 提示语固定为：`请输入整数（输入 0 结束）：`
2. 用 `while` 循环 + `break` 实现（读到 0 就跳出）；
3. 统计并输出**5 行**（顺序、标签、格式必须完全一致）：

```text
count   = 个数
sum     = 总和
max     = 最大值
min     = 最小值
average = 平均值（保留 2 位小数）
```

4. **如果没有输入任何数据**（第一个就是 0），只输出一行：`没有输入任何数据`
   （注意：此时不能算平均值，否则就是**除以零** —— 第 3 课的坑，这里正好用 `if` 挡住）
5. 平均值用 `%.2f`，别忘了第 3 课的整数除法陷阱。

**⚠️ 提示（这是本题最大的坑）**：`max` 和 `min` 该初始化成什么？
我先告诉你：**如果初始化成 0，遇到"全是负数"的输入就会错。**
我的基准表里专门有一组全是负数的数据 —— 想想怎么初始化才稳妥。

**我的实测基准表（我会逐条验证）**

| --- | --- |
| `23 7 99 42 5 0` | `count   = 5`<br>`sum     = 176`<br>`max     = 99`<br>`min     = 5`<br>`average = 35.20` |

## 必做 2 ⭐⭐⭐ 改错题（1 error + 1 warning + **4 个零警告错误**）

**文件**：[task2_fixme.c](task2_fixme.c)

下面这段代码有 **6 个问题**：

- **1 个 error**（编译直接失败）
- **1 个 warning**（编译期能看到）
- **4 个编译器完全不报错、但结果是错的** ⚠️ **本课重点**

```c
#include <stdio.h>

int main(void)
{
    for (int t = 0; t < 3; t++);
    {
        printf("A ");
    }
    printf("\n");

    int sum = 0;
    for (int k = 1; k < 5; k++) {
        sum += k;
    }
    printf("1~5 的和 = %d\n", sum);

    for (int a = 1; a <= 3; a++) {
        for (int b = 1; b <= 3; b++) {
            if (a * b == 4) {
                printf("找到 a=%d b=%d\n", a, b);
                break;
            }
        }
        printf("外层 a=%d 走完\n", a);
    }

    int sumOdd = 0;
    for (int k = 1; k <= 10; k++) {
        sumOdd += k;
        if (k % 2 == 0) {
            continue;
        }
    }
    printf("奇数和 = %d\n", sumOdd);

    int steps = 0;
    for (int k = 0; k < 10; k++) {
        k += 2;
        steps++;
    }
    printf("steps = %d\n", steps);

    int n = 5;
    for (int idx = 1; idx <= n; idx++) {
        /* 只是数次数 */
    }
    printf("循环共执行了 %d 次\n", idx);

    return 0;
}
```

## 必做 3 ⭐⭐⭐ 数位拆解循环：位数 / 各位和 / 反转数

**文件**：[task3_number.c](task3_number.c)

**任务**：读入一个正整数，用**循环**做数位拆解。

**要求**

1. 提示语固定为：`请输入一个正整数（1~999999）：`
2. **必须用循环**（`while` 或 `for` 都行），不许硬编码位数；
3. 核心套路是 `while (n > 0) { digit = n % 10; ... n /= 10; }`；
4. 输出**4 行**，标签和格式必须完全一致：

```text
原数   = 原数
位数   = 位数
各位和 = 各位数字之和
反转数 = 反转后的数
```

5. **注意**：循环会把 `n` 改掉，所以**先把原数备份**到一个变量里再打印 `原数`；
6. 反转的公式是 `reverse = reverse * 10 + digit`（讲义第 6 节有推导）。

**我的实测基准表（我会逐条验证）**

| 输入 | 我实测的标准输出 |
| --- | --- |
| `12345` | `原数   = 12345`<br>`位数   = 5`<br>`各位和 = 15`<br>`反转数 = 54321` |
| `100` | `原数   = 100`<br>`位数   = 3`<br>`各位和 = 1`<br>`反转数 = 1` |
| `7` | `原数   = 7`<br>`位数   = 1`<br>`各位和 = 7`<br>`反转数 = 7` |
| `999999` | `原数   = 999999`<br>`位数   = 6`<br>`各位和 = 54`<br>`反转数 = 999999` |
| `10` | `原数   = 10`<br>`位数   = 2`<br>`各位和 = 1`<br>`反转数 = 1` |

> 💡 **`100` 那组要特别想清楚**：反转后为什么是 `1` 而不是 `001`？
> 因为整数没有"前导零"这个概念 —— `001` 就是 `1`。
> 另外 `10` 反转也是 `1`，同样道理。

**我会检查什么**

- 上表 5 组输入逐条比对（`100`、`10` 这两组最容易出错）；
- 是否真的用循环拆位（不是写死 5 位、6 位）；
- 0 错误 0 警告。

**任务**：用嵌套循环找出 2~100 之间的所有质数并打印。

**要求**

2. 输出格式：每个质数后面跟**一个空格**，**每输出 10 个换一行**；
3. 最后单独一行输出总数；
4. 我实测的基准输出（逐字符比对，注意行尾那个空格）：

```text

```

5. **思考题**（写在注释里，用文字回答）：
