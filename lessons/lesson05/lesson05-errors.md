# 第 5 课 · 常见报错速查（真实原文对照）

> 所有报错信息都是**在你自己的电脑上实测粘贴下来的**（Apple clang 21 / macOS arm64）。
>
> **第 5 课有个新情况：最危险的错误，编译器一个字都不说。**
> 前四课我们说"编译通过 ≠ 结果正确"；这一课升级成
> **"编译通过 ≠ 结果正确 ≠ 程序会停下来"** —— 循环可能**永远不停**。

## 一、本课关键词总览

| 关键词 | 出现在哪 | 严重程度 | 意味着 |
| --- | --- | --- | --- |
| `-Wempty-body` | 编译 warning | 中 | `while (...);` / `for (...);` —— 循环体是空的 |
| `-Wparentheses` | 编译 warning | 中 | `while (x = 5)` —— 条件里写了赋值（和第 4 课 `if` 一样） |
| `use of undeclared identifier` | 编译 error | 低 | 在 `for` 里声明的变量，循环外用了 |
| **死循环** ⚠️ | **无任何提示** | **最高** | 程序永远不停，只能 `Control + C` |
| **差一错误 / break 只跳一层 / continue 位置 / 改循环变量** | **无任何提示** | **高** | 结果悄悄不对 |

## 二、`while (...);` 和 `for (...);`：空循环体（`-Wempty-body`）

**真实警告（while 版）：**

```text
w1.c:2:42: warning: while loop has empty body [-Wempty-body]
    2 | int main(void) { int i = 0; while (i < 3); { printf("只执行一次\n"); i++; } return 0; }
      |                                          ^
w1.c:2:42: note: put the semicolon on a separate line to silence this warning
1 warning generated.
```

**真实警告（for 版）：**

```text
w2.c:2:45: warning: for loop has empty body [-Wempty-body]
    2 | int main(void) { for (int k = 0; k < 3; k++); { printf("for 后面分号\n"); } return 0; }
      |                                             ^
w2.c:2:45: note: put the semicolon on a separate line to silence this warning
1 warning generated.
```

### ⚠️ 但两者的后果**完全不同** —— 这一点必须分清

| 写法 | 会发生什么 |
| --- | --- |
| `while (i < 3);` + 下面的块 | **死循环！** 因为 `i++` 在循环**外面**，`i` 永远是 0，条件永远成立 |
| `for (int k = 0; k < 3; k++);` + 下面的块 | 循环正常跑 3 次（`k++` 在 for 头部，不在循环体里），然后往下走 |

**我实测过**：`while (i < 3);` 这个程序**跑了一秒都没停**，
只能用超时强杀（等价于退出码 `124`）—— 这就是死循环。

**怎么改**：把那个"孤零零的分号"去掉，让 `{}` 成为循环体：

```c
while (i < 3);          /* ❌ 分号成了循环体，{} 里的 i++ 永远不会被执行 */
{ printf("A "); i++; }

while (i < 3) {         /* ✅ */
    printf("A ");
    i++;
}
```

> **纪律：`while (...)` 和 `for (...)` 后面，永远不要出现裸分号。**
> 真要"空转"（比如故意延时），就写 `{}` 并加注释说明 —— 让意图可见。

## 三、`for` 里声明的变量，出了循环就不存在（编译 error）

**真实报错：**

```text
hw5b.c:47:43: error: use of undeclared identifier 'idx'
   47 |     printf("循环共执行了 %d 次\n", idx);
      |                                    ^~~
1 error generated.
```

| 项目 | 内容 |
| --- | --- |
| **人话** | "用了未声明的标识符 `idx`" |
| **原因** | `for (int idx = 1; ...)` 里的 `idx` 作用域**只在这个 for 内部**（C99 起） |
| **怎么改** | 在外面单独声明一个计数器：`int count = 0;`，循环里 `count++`，循环后打印 `count` |
| **为什么这样设计** | 把变量的作用域**限制到最小**，避免它污染外面的代码（这是好设计，不是坑） |
| **老写法（C89）** | 那时不允许在 for 里声明变量，必须写成 `int i; for (i = 0; ...)` —— 两种都见过即可 |

**顺带提醒**：如果你外面正好也有个同名变量，**不会报错**，但会**遮蔽（shadow）** ——
`for (int i = ...)` 里的 `i` 和外层的 `i` 是两个不同的变量，改一个不影响另一个。
这种"不报错但容易搞混"的情况，用一个词形容：**危险**。所以变量名尽量别重名。

## 四、⚠️ 死循环：编译器**完全不警告**（本课最危险）

我实测了三种典型死循环，**都用 1 秒超时验证过：全部停不下来。**

| 死循环写法 | 为什么会死 |
| --- | --- |
| `while (i < 5) { printf("%d ", i); }` | 忘了 `i++`，条件永远成立 |
| `for (int k = 0; k < 10; ) { if (k % 2 == 0) { continue; } k++; }` | `continue` 跳过了 `k++`，`k` 永远是 0 |
| `while (1) { }` | 条件本来就是"永远真"（有时是故意的，但要自己负责） |

**实测结果：**

```text
w8.c  while (1) { }          空循环  → ⏱ 1 秒内没停，确认是死循环
w4.c  忘记 i++               死循环  → ⏱ 1 秒内没停，确认是死循环
w5.c  continue 之前忘了更新   死循环  → ⏱ 1 秒内没停，确认是死循环
```

**怎么中止？** 在运行它的终端里按 **`Control + C`**（Linux/macOS 都是这个）。

**怎么预防？三要素检查法** —— 每写一个循环，问自己：

1. **初始化**了吗？（循环变量有没有初值）
2. **条件**会在某一刻变成假吗？（它依赖的变量，有没有东西在改变它）
3. **更新**在哪？（每轮结束前，那个变量有没有朝着"条件变假"的方向走）

> 💡 第 3 条是最容易漏的。**"每个循环必须有人负责让条件变假"** ——
> 这句话请记住。如果负责这件事的语句被 `continue` 跳过了，循环就永远不停。

## 五、差一错误（off-by-one）：**零警告**

**真实运行结果（我实测）：**

```text
  i < 5  时求和 = 10   （累加了 4 个数）
  i <= 5 时求和 = 15   （累加了 5 个数）—— 差一个 5！
```

| 项目 | 内容 |
| --- | --- |
| **原因** | `<` 和 `<=` 差一次循环，结果可能差很多 |
| **零警告原因** | 两种写法语法都完全合法，编译器无从判断你想要哪个 |
| **怎么避免** | 写之前先想清楚："我想要的是 **n 次** 还是 **0~n**？" |
| **最常见的两个场景** | ① 求和 1~5 应该用 `i <= 5`；② 遍历下标 0~n-1 应该用 `i < n`（第 7 课数组会用到） |

**一个自检技巧**：拿最小的例子手算一遍。比如 `n = 1` 时循环跑几次？`n = 2` 时呢？

## 六、`break` 只跳出一层循环：**零警告**

**真实运行结果（嵌套循环里 `if (b == 2) break;`）：**

```text
  (1,1) 外层 a=1 这一轮还是走完了
  (2,1) 外层 a=2 这一轮还是走完了
```

| 项目 | 内容 |
| --- | --- |
| **原因** | `break` 只结束**离它最近的那一层**循环 |
| **怎么跳两层** | 用**标志变量**，在外层循环的条件里检查它（见下面代码） |
| **为什么不能直接跳两层** | C 没有"带标签的 break"（Java 有 `break label;`，C 没有） |

```c
int found = 0;                                  /* 标志变量 */
for (int i = 1; i <= 3 && !found; i++) {        /* 外层条件里检查标志 */
    for (int j = 1; j <= 3; j++) {
        if (i * j == 4) {
            found = 1;                          /* 立起标志 */
            break;                              /* 先跳出内层 */
        }
    }
}
```

> 顺带回答一个常见疑问：**`switch` 里的 `break` 只结束 `switch`，不会结束外面的循环**（第 4 课学过）。
> 两处 `break` 是同一条规则：**结束最近的那个"可跳出结构"。**

## 七、`continue` 的位置错了：**零警告**

**真实运行结果（本想在 1~10 里只累加奇数）：**

```text
奇数和 = 55     ← 它把 1~10 全加了！
```

| 项目 | 内容 |
| --- | --- |
| **原因** | 累加语句写在 `if (...== 0) continue;` **之前**，所以偶数也先被加进去了 |
| **正确结果** | `1+3+5+7+9 = 25` |
| **怎么改** | 把"跳过判断"放在**累加之前** |
| **为什么零警告** | 语法完全合法，只是逻辑顺序反了 |

```c
/* ❌ 先加再判断 */
for (int k = 1; k <= 10; k++) {
    sumOdd += k;                    /* 偶数也加了 */
    if (k % 2 == 0) { continue; }
}

/* ✅ 先判断再处理 */
for (int k = 1; k <= 10; k++) {
    if (k % 2 == 0) { continue; }    /* 偶数直接跳过 */
    sumOdd += k;
}
```

## 八、在循环体里改循环变量：**零警告**，次数完全失控

**真实运行结果：**

```text
steps = 4      ← 本想跑 10 次
```

| 项目 | 内容 |
| --- | --- |
| **原因** | `for` 每轮结束还会执行一次 `k++`，你在循环体里又 `k += 2`，等于每轮加 3；很快越过 10，循环提前结束 |
| **怎么改** | **不要在循环体里修改循环变量**。真要按特殊步长走，就在 for 头部写清楚：`for (k = 0; k < 30; k += 3)` |
| **为什么零警告** | 语法合法，逻辑失控 |

## 九、`while` 的条件里写赋值（`-Wparentheses`，和第 4 课同一条规则）

**真实警告：**

```text
w3.c:2:38: warning: using the result of an assignment as a condition without parentheses [-Wparentheses]
    2 | int main(void) { int i = 0; while (i = 5) { printf("%d ", i); } return 0; }
      |                                    ~~^~~
w3.c:2:38: note: place parentheses around the assignment to silence this warning
w3.c:2:38: note: use '==' to turn this assignment into an equality comparison
```

**后果**：条件恒为 5（真）→ **死循环**，而且 `i` 永远是 5。

| 结论 | 第 4 课学的那条规则，在 `while` 上一模一样：**看到这个警告就去改 `==`，别用双括号消警告。** |

## 十、速查小结（建议打印）

| 你看到的 / 遇到的 | 原因 | 一句话修法 |
| --- | --- | --- |
| `-Wempty-body`（while/for） | 循环后面多了分号 | 删掉分号；真要空转就写 `{}` 加注释 |
| `-Wparentheses`（while 条件） | `while (x = 5)` | 改成 `==` |
| `use of undeclared identifier` | 用了 for 里声明的变量 | 在外面声明计数器 |
| **程序停不下来** | 忘更新 / `continue` 跳过更新 / `while(1)` | `Control + C`；检查三要素 |
| **求和少加/多加一个** | 差一错误 `<` vs `<=` | 用最小例子手算验证 |
| **循环没有如期结束** | `break` 只跳一层 | 用标志变量 |
| **该跳过的没跳过** | `continue` 位置错了 | 把判断放到处理之前 |
| **循环次数不对** | 循环体里改了循环变量 | 别在循环体里改它 |

## 十一、写完循环之后的自检四问

1. **初始化、条件、更新，三要素都齐了吗？**（谁负责让条件变假？）
2. **`continue` 有没有跳过那个"负责更新"的语句？**（这会直接导致死循环）
3. **`break` 我是不是以为它能跳两层？**（它只跳一层）
4. **边界是 `<` 还是 `<=`？**（拿最小例子手算一遍）
